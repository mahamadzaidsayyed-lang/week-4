# Week 4 Task: Dashboard and Report Creation (Healthcare)

Conceptual dashboard (wireframe + mock layout) and written report for healthcare administrators, using **simulated** data from the Week 2 and Week 3 analyses.

## Files
| File | Purpose |
|---|---|
| `Dashboard_Report.docx` | Main deliverable: report with wireframe, mock layout and narrative |
| `make_dashboard_images.py` | Draws the wireframe and the mock dashboard |
| `images/wireframe.png` | Annotated wireframe |
| `images/mock_dashboard.png` | Mock dashboard populated with simulated data |
| `data/` | Simulated inputs used by the mock layout |

## Run
```
pip install pandas numpy matplotlib
python make_dashboard_images.py
```
